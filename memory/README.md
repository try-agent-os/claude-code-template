# Memory

Durable knowledge the agent curates across sessions. Plain markdown, small
files, meaningful names — not a database.

Start with `owner.md` (copy `owner._template.md`). Grow `people/`,
`decisions/`, `playbooks/` and other subdirectories as the instance
accumulates things worth remembering.

Never secrets. This directory is committed and synced back to the repo on
every checkpoint — anything written here should be safe to read on any
device with repo access.
