# Скилл: Анализ сигналов

Аналитический фреймворк для обработки сигналов из `${CLAUDE_PROJECT_DIR}/memory/signals.md`.

## Типы сигналов

| Тип | Описание | Пример |
|-----|----------|--------|
| lead | Потенциальный клиент | Запрос в ЛС, упоминание бюджета |
| trend | Тренд рынка | Рост спроса на AI-интеграции |
| request | Запрос от клиента/контакта | "Можете сделать X?" |
| problem | Проблема, которую можно решить | Жалоба в чате на инструмент |
| idea | Идея для продукта/контента | Тема для поста, фича для сервиса |

## Скоринг

- **high** — явный лид, прямой запрос, конкретная потребность с бюджетом
- **med** — косвенный сигнал, интерес без конкретики, релевантный тренд
- **low** — фоновый шум, общие обсуждения, далекие от текущего фокуса

## Группировка

Связанные сигналы → паттерн:
- 2+ сигналов на одну тему → создай/обнови паттерн в `${CLAUDE_PROJECT_DIR}/memory/patterns.md`
- Формат: `### Паттерн: название`, confidence = 0.5 (начальный), sources = список сигналов
- Существующий паттерн + новый сигнал → confidence += 0.1

## Конверсия в задачи

Сигнал с суммарным score >= 3 (или один high) → создай задачу в saga-mcp:
- Scope: конкретные шаги (пронумерованные)
- Acceptance criteria: как проверить что готово
- Контекст: ссылки на исходные сигналы

## Создание opportunities

Формат записи в `${CLAUDE_PROJECT_DIR}/memory/opportunities.md`:
```
### OPP-NNN: Название
- **Источник:** сигнал или паттерн
- **Потенциал:** high/med/low
- **Следующий шаг:** конкретное действие
- **Создано:** YYYY-MM-DD
- **Статус:** active | dismissed | converted
```

Нумерация: найди последний OPP-NNN, инкремент +1.

## Aging opportunities

- Opportunity active > 72ч без движения → решение:
  - Есть новые данные → обнови следующий шаг
  - Нет данных, все еще актуально → escalate
  - Неактуально → dismiss с причиной

## HIGH-триггер

High-потенциал сигнал (явный лид, прямой запрос с бюджетом) → сначала ВЕРИФИЦИРУЙ:

| Источник сигнала | Что проверить |
|-----------------|--------------|
| Telegram | Gmail за последние 24ч по ключевым словам события |
| Gmail | Timeline контакта + Telegram signals.md |
| Web/scan | signals.md на дубликаты + CRM pipeline |

Если сигнал ВЕРИФИЦИРОВАН (подтвержден хотя бы одним дополнительным источником):
→ создай opportunity + задачу HIGH немедленно

Если сигнал ОДИНОЧНЫЙ (только один источник, без подтверждения):
→ создай задачу [MED] "Верифицировать сигнал: {название}"
→ запиши в signals.md с пометкой "unverified, source: {источник}"
→ НЕ создавай opportunity, не алертить пользователя

Исключение: прямой запрос от существующего активного клиента → HIGH немедленно.
