# Скилл: Разблокировка задач

Протокол для работы с заблокированными задачами в saga-mcp.

## Шаг 1: Самостоятельная разблокировка

Прежде чем эскалировать — попробуй решить сам:

- **Можно обойти?** Альтернативный API, другой инструмент, другой подход
- **Можно декомпозировать?** Разбить на части, сделать что можно сейчас
- **Данные доступны иначе?** Другой источник той же информации

Примеры:
- "Контакт не найден" → tdl users, web search, gmail search, CRM, fireflies транскрипты
- "Нет API ключа" → бесплатная альтернатива? Можно обойти без ключа? Есть другой сервис?
- "Нет доступа к чату" → tdl chat ls, попросить инвайт, найти публичный аналог
- "Не хватает контекста" → memory files, telegram history, gmail, fireflies

Если удалось разблокировать → смени статус на `in_progress`, обнови scope.

## Шаг 2: Конкретный запрос

Если самостоятельно не решить — сформулируй запрос юзеру:

**Плохо:** "Нужны креды для GitHub API"
**Хорошо:** "Добавь GITHUB_TOKEN в .env файл. Создать токен: Settings → Developer → Personal access tokens → Fine-grained. Scope: repo (read). Ожидаемый формат: `GITHUB_TOKEN=ghp_xxx`"

Принципы:
- Минимум действий от юзера
- Конкретная инструкция (куда, что, как)
- Ссылка на место где создать/найти нужное
- Ожидаемый формат/результат

Запрос → задача в saga-mcp с приоритетом MED, тип: `awaiting_user`.

## Шаг 3: Aging

Каждые 24ч переоценивай заблокированные задачи:

1. **Еще актуально?** Контекст мог измениться, приоритеты сдвинуться
2. **Новые данные?** Может появились новые сигналы/контакты
3. **Альтернативный путь?** С новым контекстом может быть другое решение

Правила aging:
- Max 3 escalations на одну задачу
- После 3 escalations → статус `awaiting_user`, больше не эскалировать
- Задача blocked > 7 дней без движения → предложи архивировать
