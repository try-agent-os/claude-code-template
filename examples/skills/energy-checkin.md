# Energy Check-in — Процедура

## Когда вызывать

- 08:00 — утренний check-in (после re-parenting check-in Vasily)
- 13:30 — пост-lunch check-in (после Lunch + walk recurring)
- 18:00 — EOD check-in (перед или вместо Check chats EOD)

Запускается dispatcher'ом по schedule (saga task с time-based trigger) или вручную.

## Контекст (важно для тонa)

Vasily ADHD + identity-нужда (life-long pattern). Его симптом: понедельник мощный → к среде сдувается → забил. Нужно:
- НЕ давить «соберись», «надо», «время идет»
- НЕ оценочно («ты опять...»)
- Конструктивно — если энергия низкая, предложить КОНКРЕТНЫЕ корректировки дневного плана
- Сухо но тепло — коротко, по-деловому, без воды

## Формат сообщений

### Утренний (08:00)

```
🌅 Доброе утро.

• Энергия 1-10?
• Как сон вчера (часов / качество)?
• 3 главных дела на сегодня — какие?

(Если энергия < 5 — скажи, перепланируем.)
```

### Пост-lunch (13:30)

```
🍴 После обеда.

• Энергия 1-10?
• Что сделано из 3 главных?
• Что съело время не по плану?
• Корректировки нужны?
```

### EOD (18:00)

```
🌇 EOD.

• Энергия 1-10?
• 3 главных — закрыты?
• Что осталось на завтра?
• На что хватило сил, на что нет?
```

## Threshold-driven response

- **Energy >= 7**: похвалить кратко («устойчиво держишь, продолжай»). Без overdo.
- **Energy 5-6**: подтвердить нормально, спросить нужны ли паузы. Не паниковать.
- **Energy < 5**: ВКЛЮЧИТЬ adaptive mode:
  - Ни разу не «соберись»
  - Спросить «что хочешь — перенести, отменить, удлинить break?»
  - Предложить конкретно: «давай уберу X с сегодня, перенесу на чт» (через update_event)
  - Если паттерн на день / неделю (3 raz подряд < 5) — sympathy + напомнить что это нормально, identity-нужда тут активируется, не значит что ты failing

## Tracking (накопительный)

После каждого ответа Vasily — записать в `memory/health/energy-log.md` (создать если нет):

```
| Дата/время | Энергия | Сон | Note |
|-----------|---------|-----|------|
| 2026-05-04 08:00 | 7 | 7ч 30м | пн утро, после спартанцев |
```

Через 2 недели накопится паттерн: где конкретно сдувается (день / час / триггер). Это даст signal для адаптации плана.

## Что НЕ делать

- Не пинговать если Vasily пишет что хочет тишины ("не беспокой", "молчи", "потом")
- Не пинговать в 22:30+ (wind-down защищен)
- Не дублировать пинги в течение 2ч
- Не превращать в чек-лист — Vasily может ответить кратко («7») и это ОК. Не вытягивать всё.
- Не давать unsolicited advice. Только если энергия < 5 ИЛИ Vasily просит.

- Что записывать в log
